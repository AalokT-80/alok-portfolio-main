# Portfolio

My personal portfolio site. Nothing fancy — just HTML, CSS, and vanilla JavaScript.

## What's here

A single-page site that shows my work, skills, and background. Built it to have something simple to point people to.

## Tech

- Plain HTML/CSS/JS
- No frameworks, no build step
- Canvas animation in the background (turns off if you prefer reduced motion)
- Scroll animations via IntersectionObserver

## Why it looks like this

Started with more effects and rolled most of them back. The minimal version ended up looking better than the flashy one. Dark theme because I stare at dark screens all day anyway.

## Running locally

Just open `index.html` in a browser. That's it.

## Files

```
index.html   - the page
style.css    - styles
script.js    - canvas + scroll animations
```
